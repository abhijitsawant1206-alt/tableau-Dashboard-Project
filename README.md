# HR Data Dashboard (Tableau)
Project Overview:

This project is an interactive HR data dashboard created using Tableau. It provides insights into employee data, helping organizations understand workforce trends and make informed decisions.

Objectives:

Analyze employee distribution
Understand attrition trends
Track department-wise performance
Identify patterns in hiring and employee retention

Tools and Technologies:

Tableau
Data visualization techniques
Data analysis

File Included:

hrdata.twb – Tableau dashboard file

Key Features:

Employee overview including total employees and demographics
Department-wise analysis
Attrition and retention insights
Interactive filters for deeper exploration

How to Use:

Download the Tableau workbook file
Open it using Tableau Desktop
Use filters and visuals to explore the dashboard

Insights:

Employee distribution across departments
Attrition trends over time
Key factors affecting employee retention

Future Improvements:

Add predictive analytics for attrition
Improve dashboard design and usability
Integrate additional HR metrics
